# My Website

A simple static website scaffold built with HTML, CSS, and JavaScript.

## Files

- `index.html` — main page content
- `styles.css` — page styling
- `script.js` — tiny JavaScript interaction

## Run locally

Open `index.html` in your browser.

## Customize

- Edit the headings and text in `index.html`
- Change colors or spacing in `styles.css`
- Add JavaScript behavior in `script.js`
