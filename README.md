# BM Digital Solutions Website

A polished static business website for BM Digital Solutions with multiple pages, responsive design, dark mode, animations, a contact form, SEO metadata, and a WhatsApp call-to-action.

## Files

- `index.html` — home page
- `about.html` — about page
- `services.html` — services page
- `pricing.html` — pricing page
- `portfolio.html` — portfolio page
- `contact.html` — contact page
- `privacy.html` — privacy policy page
- `terms.html` — terms and conditions page
- `styles.css` — shared styling
- `script.js` — interactive behavior
- `robots.txt` — search engine crawling instructions
- `sitemap.xml` — sitemap for SEO

## Run locally

Open `index.html` in a browser, or serve the folder with a simple local server such as:

```bash
python -m http.server 8000
```

Then open http://localhost:8000.
